CORRECAO 2 — Corrigir Canonical URL para o dominio real
-------------------------------------------------------
PRIORIDADE: CRITICA

Problema:
  Todas as paginas declaram canonical para `https://samirtrindade.com.br/`
  mas o site esta hospedado em `https://samirtrindade.vercel.app`.

  Se o dominio final e .com.br, precisa garantir redirect 301 de .vercel.app
  para .com.br. Se o dominio final e .vercel.app, os canonicals estao errados.

Acao:
  1. Confirme com o usuario qual e o dominio final pretendido.
  2. Se for .com.br:
     - Verifique se ja existe redirect 301 de .vercel.app para .com.br
     - Se nao existir, configure no Vercel (vercel.json) ou no DNS/registrar
  3. Se for .vercel.app:
     - Atualize TODOS os canonicals para apontar para samirtrindade.vercel.app
  4. Rode `npm run build` e confirme.

CORRECAO 3 — Criar robots.txt e corrigir referencia do sitemap
---------------------------------------------------------------
PRIORIDADE: CRITICA

Problema:
  1. /robots.txt retorna 404 (nao existe)
  2. No <head>, o link aponta para /sitemap-index.xml (404)
     mas o arquivo real e /sitemap.xml

Acao:
  1. Crie o arquivo public/robots.txt (ou equivalente) com:
     ```
     User-agent: *
     Allow: /
     Sitemap: https://samirtrindade.com.br/sitemap.xml
     # ou https://samirtrindade.vercel.app/sitemap.xml se esse for o dominio final
     ```
  2. Corrija a referencia no <head> de TODAS as paginas:
     De:  <link rel="sitemap" href="/sitemap-index.xml">
     Para: <link rel="sitemap" href="/sitemap.xml">
  3. Rode `npm run build` e confirme que dist/robots.txt existe.

CORRECAO 4 — Adicionar Article Schema nos posts do blog
--------------------------------------------------------
PRIORIDADE: ALTA

Problema:
  Os 3 posts do blog tem apenas LocalBusiness Schema. Falta Article Schema
  para rich snippets de artigo no Google (titulo, autor, data, imagem).

Acao:
  1. Em cada pagina de blog (/blog/[slug] ou template equivalente),
     adicione um bloco JSON-LD do tipo Article com:
     - @type: "Article"
     - headline: titulo do artigo
     - description: meta description do artigo
     - author: { @type: "Person", name: "Samir Trindade" }
     - publisher: { @type: "Organization", name: "Samir Trindade", logo: URL }
     - datePublished: data do artigo
     - dateModified: mesma data (ou data real de edicao)
     - image: URL da imagem do artigo
     - url: canonical do artigo
     - articleSection: "Plano de Saude"
  2. Mantenha o LocalBusiness Schema tambem (pode haver multiplos blocos
     JSON-LD na mesma pagina).
  3. Rode `npm run build` e valide com Google Rich Results Test.

CORRECAO 6 — Adicionar BreadcrumbList Schema em todas as paginas
----------------------------------------------------------------
PRIORIDADE: ALTA

Problema:
  Nenhuma pagina tem BreadcrumbList Schema. O Google nao exibe breadcrumbs
  nos resultados de busca.

Acao:
  1. Crie um componente SchemaBreadcrumb.astro (ou equivalente) que receba
     um array de items {name, url} e renderize:
     ```json
     {
       "@context": "https://schema.org",
       "@type": "BreadcrumbList",
       "itemListElement": [
         { "@type": "ListItem", "position": 1, "name": "Inicio", "item": "https://.../" },
         { "@type": "ListItem", "position": 2, "name": "Servicos", "item": "https://.../servicos/" },
         { "@type": "ListItem", "position": 3, "name": "Plano de Saude Amil" }
       ]
     }
     ```
  2. Adicione em todas as paginas com hierarquia:
     - Home: apenas "Inicio"
     - /sobre: Inicio > Quem Somos
     - /servicos: Inicio > Servicos
     - /servicos/amil: Inicio > Servicos > Plano de Saude Amil
     - /blog: Inicio > Blog
     - /blog/artigo: Inicio > Blog > Titulo do Artigo
     - /contato: Inicio > Contato
  3. Rode `npm run build` e confirme.

CORRECAO 7 — Adicionar FAQPage Schema nas paginas com FAQ
---------------------------------------------------------
PRIORIDADE: ALTA

Problema:
  Nenhuma pagina tem FAQPage Schema. Se houver secao de perguntas frequentes,
  o Google pode exibir accordion nos resultados.

Acao:
  1. Verifique se alguma pagina (home, /servicos, ou posts) tem secao de FAQ.
  2. Se houver, adicione FAQPage Schema:
     ```json
     {
       "@context": "https://schema.org",
       "@type": "FAQPage",
       "mainEntity": [
         {
           "@type": "Question",
           "name": "Pergunta 1",
           "acceptedAnswer": {
             "@type": "Answer",
             "text": "Resposta 1"
           }
         }
       ]
     }
     ```
  3. Minimo 3 perguntas por pagina.
  4. Rode `npm run build` e confirme.

CORRECAO 9 — Otimizar performance (preconnect, preload LCP)
-------------------------------------------------------------
PRIORIDADE: MEDIA

Problema:
  - Sem preconnect para images.unsplash.com
  - Sem preload para imagem hero/LCP
  - Sem fetchpriority="high" em nenhuma imagem

Acao:
  1. Adicione no <head>:
     ```html
     <link rel="preconnect" href="https://images.unsplash.com">
     <link rel="dns-prefetch" href="https://images.unsplash.com">
     ```
  2. Identifique a imagem hero/LCP de cada pagina.
  3. Adicione preload:
     ```html
     <link rel="preload" as="image" href="/hero.jpg"
           fetchpriority="high" imagesrcset="...">
     ```
  4. Adicione `fetchpriority="high"` na tag <img> da imagem hero.
  5. Rode `npm run build` e confirme.
